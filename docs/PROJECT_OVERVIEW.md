# Project Overview

Biz Manager Dashboard is a portfolio demo of a business operations system for managing customers, sales, invoices, expenses, inventory, staff, and reports from a clean dashboard.

The goal of this public version is to demonstrate full-stack app structure, dashboard design, CRUD workflows, and practical business logic without exposing private development history or environment-specific details.

## Repository Shape

- `frontend` contains the Next.js dashboard UI.
- `backend` contains the Express API and business workflow logic.
- `supabase/migrations` contains PostgreSQL schema migrations.
- `public/screenshots` is reserved for cleaned demo screenshots.
